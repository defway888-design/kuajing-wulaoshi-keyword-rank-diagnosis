# 跨境吴老师业务规则

## 0. 接入检查优先于业务运行

每次运行先按入口指令检查当前会话是否可访问已配置、启用并授权的西柚 MCP 及日级反查能力。未配置、连接/授权失败、状态无法确认或缺少日级能力时立即停止，并提示配置或修复相应问题；检查通过前不补问业务参数、不抓取商品、不统计、不生成业务报告。不能用旧文件、离线数据或其他源绕过。配置完成后重新检查；安装 Skill 不等于配置 MCP。只读发现和连接检查不要求用户额外提供业务输入或密钥。

## 1. 输入与权限

### 运行对话中的输入流程

这三个字段由用户在运行时的当前对话框按提示输入，而不是修改提示词、Skill、配置文件或脚本参数。接入检查先行；未通过时只提示配置或修复，不进入参数填写阶段。

1. 尚未收到本次参数时，发送“跨境吴老师需要本次分析参数，请直接在当前对话框回复”，随后依次列出 ASIN（必填）、站点（必填，国家名称或站点代码）、抓取天数（选填，留空或回复“默认”使用 3 天）。三个字段可以一起回复，也可以分条补齐。
2. 发出提示后等待用户回复；没有回复不继续业务抓取。宿主支持原生对话输入组件时可以使用，不支持时直接在普通聊天中提示并等待。不得要求外部页面、上传文件、手工 JSON 或编辑占位符。
3. 仅使用本次分析的对话输入。本次启动消息已提供有效参数时直接接收，不重复要求填写；部分已提供时保留，后续只补问缺失、冲突或无效内容。不能默用以前分析过的 ASIN、站点或日期。
4. 收到回复后校验：ASIN、站点仍缺失时继续等待补充；天数未提供、留空或明确使用默认值时取 3。天数明确填了非法值（例如零、负数或非整数）时要求更正，不能悄悄改成 3。自然语言表达能明确解析为正整数天数时，可转换为整数。
5. 必填项齐全且有效后，简短复述本次 ASIN、站点与天数；缺省天数标明“默认 3 天”，然后进入数据流程，无需再强制一次“确认”。存在歧义则先澄清，不进行抓取。
6. 对话中的采集由宿主 AI 完成；内部标准化 JSON 和脚本输入由 AI 生成，不转嫁给用户。新增任务重新获取该任务的输入，不从历史文件填充。

### 字段校验和权限

- 单个 ASIN：去除首尾空白、转大写后检查为 10 位字母或数字；不限制必须以某个前缀开头。格式通过不代表商品存在。
- 站点：从本次用户明确提供的国家或 Amazon 站点可靠映射为当前接口支持的国家码；不默认美国，不跨站替代。
- 天数 N：未提供、留空或明确使用默认值时为 3；其他输入解析后必须为正整数。允许 N=1，报告标注“单日观测”；此时持续出现类仅表示 1/1 天出现，不暗示多日稳定，两个“观察词”类别自然为空。
- 超出接口支持站点或历史范围时说明限制，不擅自缩短 N、换站点或改用周/月数据。只询问必要的缺失或无效输入。
- 不新增商品所有权、广告状态、Listing 文本或卖点输入；不据此执行任何写入操作。

## 2. 数据源与窗口

默认仅使用当前连接的西柚数据。更换数据源需另行明确授权并重新核验口径；不可自动使用其他 MCP、网页或旧模拟结果替代。商品信息和逐日关键词能力分别处理，不因缺少商品标题而丢弃已有排名事实。

按数据源明确的时区、数据日及更新说明确定最近已结束的数据日候选，不使用机器本地日期直接推算其他站点的数据日。记录初始候选结束日、实际结束日、前移天数及原因。以最新已完成且可用的数据日为结束日，向前取连续 N 个日历日。

- 最新日期经数据源明确证实尚未更新时，允许整体前移窗口；相对初始候选结束日最多额外回溯 7 个日历日。这是工作流保护限制，不是西柚接口限制。
- 中间日期缺失时保留缺口，不能跳过后拼接更早日期，也不能为绕开内部缺口而移动整个窗口。
- 空列表本身不能证明未更新。只有明确的日期完成依据和完整响应支持时，零记录才是“完整零记录”；否则为“空结果，原因未确认”。
- 请求成功、HTTP 成功状态、到达最后一页、某条记录的最新时间，均不能单独证明数据日已完成。
- 无法确定日期、时区/数据日语义或完整连续窗口时，仅交付已观测事实及缺口，不输出核心建议。

## 3. 获取、分页与失败处理

每天独立请求；如接口使用起止日期，二者均设为该数据日。单次多日范围的“最新记录”不等于逐日快照。

逐日取完全部分页，不设 Top N 或关键词截断。固定该次分页的排序与过滤条件；核对请求与返回日期、页码/游标连续性、终止标志及可用的总数。不因到达工具输出上限而声称数据完整。翻页过程中发现数据版本变化、重复游标、总数冲突等无法确认完整性的情况，保留结果并标记不完整，不无限重新抓取。

临时超时或服务繁忙等每个失败请求最多额外重试 2 次，遵守接口等待要求；权限不足、无日级能力、不支持站点等不做无意义重试。保留成功页，只补失败页，重试结果按原页替换失败状态而非追加重复页。重试失败不能触发日期前移。

## 4. 标准化与逐日状态

词库为所选全部日期的关键词并集，包含仅有其他位置的词；不加入窗口外旧词或自行扩展词。关键词仅去除首尾空白，保留原文，不合并大小写、单复数、型号或词序差异。只删除完全重复的记录；不同采集时间、不同位置全部保留。

自然和广告分别使用三个状态：

| 状态 | 判定 |
|---|---|
| 已观测到 | 有明确属于该类的有效位置记录；不要求必有数值排名 |
| 未观测到 | 当日及分页完整、日期和该类覆盖范围明确，未找到相应记录 |
| 未知 | 日期、完整性、字段含义或该类覆盖范围不足以判断 |

完整当日词库中未出现某关键词，可以在明确覆盖范围内记为未观测到；不等于该词全天没有展示。已观测到的有效片段可以作为事实保留，即使该日整体不完整；但整体不完整阻止核心建议。

空值、0、字段缺失按当前接口定义解释，不统一映射为无排名；无法解释时为未知。语义未明的位置不能因同时存在另一条有效记录而被忽略，该词归数据不足。

广告类型按接口定义映射并分别保留，不能只认某一个代码。任一已确认广告类型出现即可计当天广告已观测到。推荐/关联位置根据定义确定是否广告，不凭名称一律排除或纳入。只覆盖部分广告类型时，在所有结论中附上该范围，不扩大为全部广告。

“是否出现”与“数值排名是否可得”分别记录。自然总排名、页内排名、广告页码不混用、不换算、不混合平均。广告只有页码也计出现。多次采集全部列出或可追溯展开，日出现天数最多加 1；不擅自选最佳/最差/最新记录代表全天，也不根据异步采集的小幅差异宣称精确升降。

## 5. 互斥分类

设 O=自然已观测到天数，A=广告已观测到天数，B=同日双端出现天数。先判断数据充分性；整窗不完整，或该词任一天必要状态未知/字段有歧义，归“数据不足”。其余按下表唯一归类。

| 分类 | 条件 |
|---|---|
| 自然持续出现词 | O=N，A=0 |
| 自然观察词 | 1≤O<N，A=0 |
| 广告持续出现词 | A=N，O=0 |
| 广告观察词 | 1≤A<N，O=0 |
| 同日双端覆盖词 | B≥1 |
| 交替覆盖词 | O≥1，A≥1，B=0 |
| 双端未观测到 | O=0，A=0 |
| 数据不足 | 充分性前置条件未满足 |

“持续出现”只指选定每个数据日均观测到，不代表排名数字稳定、全天连续曝光或广告效果好。并集内仅有其他位置的词可以归“双端未观测到”；空词库不需要虚构关键词填满分类。

## 6. 相关性

仅对自然持续出现词的投放建议资格应用相关性闸门；不据此删除广告独有的核查事项。

- 初步相关：标题等真实商品信息明确支持词义，进入候选；记录判断依据。
- 待核查：词义不明确、相近型号、兼容关系或关联品牌证据不足；保留疑点，暂不建议新增投放或加价。
- 明确不相关：有明确产品意图不符证据；不进入投放建议，保留排除理由。

标题缺词不证明完整 Listing 未使用该词；自然排名高不证明相关。商品信息获取失败时相关性统一待核查，排名分类照常输出，有广告无自然的文字覆盖与相关性核查照常保留。商品信息是当前快照时，不声称已核实历史 Listing 状态。

## 7. 建议与禁止事项

1. 自然持续出现且初步相关：统一同时给出两分支——“若尚未投放该关键词，考虑新增投放；若已经投放但未观测到广告展示，核查投放状态和展示条件后，考虑提高竞价。”不能任选一支作为已知广告状态。可提示核查预算、竞价、否定词、投放状态和展示资格，但不预设竞价低是根因。
2. 广告持续出现词：核心核查清单，提示“核查 Listing 文字覆盖”“核查关键词与产品相关性”；不得声称已确认缺词或不相关，不自动建议加价、否定或停投。
3. 广告观察词：进入观察清单，同样提示两项核查，并明确仅部分日期观测到广告；不与持续类同等强度展示。
4. 自然观察词、同日双端覆盖词、交替覆盖词：仅列事实与观察方向，不自动新增投放或调整竞价。继续观察不等于建议维持投放；交替出现不等于已证实投放不稳定。
5. 双端未观测到：只说明源覆盖范围内未观测到。数据不足：仅事实与缺口。二者均不生成投放建议。

禁止输出具体竞价金额、加减价比例、预算金额/增幅、具体匹配方式、广告组设置、可执行否定词清单或其他广告执行参数。缺少花费、点击、转化、ACOS、利润等真实数据时，不编造收益、因果或广告效率结论。不以本场景为由扩展抓取无关业务数据。
