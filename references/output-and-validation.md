# 跨境吴老师输出与验收

## 输出内容与展示层级

先检查接入。未配置、连接/授权失败、状态不明或缺少日级能力时，只输出明确的阻塞原因及配置/排查方向，不套用下方报告结构，不生成空业务报告或空建议清单。配置提示不含假定服务地址、密钥要求或固定机器路径。接入检查通过后，才适用以下报告结构。

报告标题：跨境吴老师自然排名与广告展示诊断看板。以下为必须保留的内容清单，不要求将全部内容在首屏平铺；实际层级按 [看板约定](dashboard-contract.md) 执行：概览与关键警示 → 清单 → 逐词逐日证据。默认交付离线 HTML 与审计 JSON，不以包外模拟页代替正式母版。

1. **数据覆盖说明**：ASIN、站点、N、单日/多日观测、初始及实际窗口、源时区与数据日依据、前移原因、每日关键词数、分页与完整性、自然/广告覆盖范围。说明广告提供的是数值排名还是仅页码。
2. **接口事实**：逐词逐日列自然状态及真实数值、广告状态/类型/页码及可得数值、采集时间。多条位置记录保留展开细节，不编造单一“当天排名”。缺数字写未提供，不写 0。事实表可独立交付，但不能静默截断。
3. **分类汇总**：八类数量，分类总数必须等于窗口关键词并集数；列自然、广告、同日双端出现天数。按类别固定顺序、类内关键词原文排序，排序不是投资优先级。不要用缺失的搜索量/转化数据编造机会评分。
4. **核心清单 A：自然持续出现、广告未观测到的投放方向**：仅列相关性初步通过的词；列覆盖天数、相关性理由与依据、已确认的两个条件分支、广告采集范围及待核查事项。
5. **核心清单 B：广告持续出现、自然未观测到的核查方向**：列每日广告证据、覆盖天数、核查 Listing 文字覆盖与产品相关性；不要求先通过相关性闸门，不声称 Listing 已缺词。
6. **观察与排除项**：广告观察词标注部分日期并给两项核查方向；其他观察/双端/交替词只列事实和观察方向；待核查、明确不相关及其理由保留；数据不足词列具体缺口。
7. **限制与待核查**：区分未获取/接口不提供/无法解释，不把广告状态、竞价、完整 Listing 等未知当成事实。不额外向用户索要这些信息作为本场景必填项。

清单 A/B 必须出现。完整且没有符合条件词时写“本期无符合条件的关键词”；因数据不足未能判定时写“数据不足，无法判定”；相关性资料不足时写“暂无可进入投放清单的关键词，相关性待核查”，不能混成“没有机会”。

数据源仅覆盖部分广告类型时，标题/说明及具体建议均限定该范围，不表述为全平台没有广告。“未观测到”不等于未投放、不等于全天无展示；“继续观察”不等于维持现有广告设置。

## 验收清单

- 西柚 MCP 接入检查在业务步骤之前，本次状态、检查时间及证据可追溯；未通过时停止并提示配置/修复，不能用历史文件绕过。
- ASIN、站点和抓取天数通过本次运行对话框按提示收集；缺必填项时已等待回复，未要求用户编辑占位符或手工 JSON，未创建外部填写页；已提供的有效参数没有重复询问。默认天数已说明，无效天数没有被静默替换。
- 已校验输入；未默认站点、替换 ASIN 或缩短天数；N=1 明确单日。
- 实际窗口连续，内部缺日未拼补；前移有确认延迟证据且不超过 7 天。
- 每日全分页与日期完成证据可追溯，空结果未被直接判定无排名。
- 使用并集、按天计数、只去完全重复；多位置/多时间事实未丢失。
- 三状态与排名数字可得性分离；范围/字段未知不能产生负向结论。
- 八类互斥且数量核对通过；观察类未误入核心；两类清单均存在。
- 相关性有证据；商品信息失败仅降级相应建议，广告独有核查仍保留。
- 输出不含具体广告金额/比例/执行设置，不宣称因果、利润或投放成效。
- 没有跨源补齐、写入广告、泄露凭据、依赖固定机器路径或另一份本机 Skill。
- 固定模板版本与 SHA256 校验通过；所有运行数据经唯一渲染器填充，页面不自行重算分类；无广告类型、日期或模拟商品的写死默认值。
- 两张空核心清单未显示对词的实际投放方向；部分数据的警示在首屏可见，折叠不隐藏未知、歧义或缺口。
- 总排名、页内排名、页码与多次采集分别保留；CSV 与页面事实一致，导出范围明示。

## 测试方式与局限

包内单元测试采用合成数据覆盖接入检查缺失/未配置/授权与连接故障/状态不明/缺少日级能力等阻塞分支，以及八类、三状态、N=1/默认 N、断日、零记录、分页失败/冲突、位置歧义、页码广告、相关性与商品信息失败、重复记录和词形差异、窗口前移边界及 CLI 不覆盖旧文件。合成接入记录只用于代码验收，不是实际 MCP 接入成功证据。

可运行测试证明统计和保护规则，不证明接口已连接、源日期完成声明真实或相关性判断一定正确。发布前另做当前西柚连接验收，记录实际 schema 与映射证据；无连接时如实标注“未进行实时接入验证”，不把离线测试写成真实模拟结果。
