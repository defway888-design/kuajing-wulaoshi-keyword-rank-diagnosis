# 跨境吴老师 Amazon自然排名与广告展示诊断 Skill

版本 **1.0.0** · 更新日期 **2026-11-23**

使用西柚 MCP 的日级关键词数据，对比单个 Amazon ASIN 的自然与广告出现情况，交付固定版式、渐进式披露的中文离线看板及审计 JSON。只提供投放和核查方向，不操作广告，不评估收益，不提供金额或调整比例。

## 安装

本仓库为公开仓库，无需提交账号、申请协作者或发送凭据。保留整个包的相对目录结构，不能只复制 `SKILL.md`。

在支持 Skill 的 AI 工具中，可以复制以下指令：

```text
作为完整 Skill 包安装到当前工具支持的 Skill 位置。先检查当前工具的安装机制，保留整个目录结构，不自动配置 MCP，不索取密钥。
```

也可从仓库下载 ZIP、解压，将完整文件夹导入所在 AI 工具支持的 Skill/知识包机制。如果工具不支持自动安装，让它读取包内 `SKILL.md` 并按相对链接继续读取所需文件；不要假设所有 AI 使用相同安装路径或命令。`agents/openai.yaml` 是可选适配元数据，不是通用运行依赖。

## 运行前提

- 当前 AI 工具支持西柚 MCP，已经配置、授权、启用，并可发现和调用日级关键词能力。
- AI 可以读取包文件、运行 Python 3.10+ 标准库程序并向用户交付 HTML/JSON 文件。
- 本包不附带 MCP 服务地址、认证参数、密钥、账号或真实运行数据。按西柚官方说明在使用者自己的 AI 工具中配置；不要在聊天中发送密钥。

未检测到可用西柚 MCP 时停止诊断并提示配置或排查，不读取旧文件或模拟数据继续运行。仅安装本 Skill 不等于完成 MCP 接入。

## 启动与输入

复制以下指令，无需先填写参数或编辑文件：

```text

先检查当前会话的西柚 MCP 接入和日级能力，通过后在当前对话框提示我输入 ASIN、站点和抓取天数。
天数留空时默认 3 天。只给优化方向，不给具体竞价金额或比例，按包内固定模板生成离线看板。
```

支持 `$` 调用的工具还可使用：


接入通过后，直接在当前对话输入：ASIN、站点、抓取天数（选填，默认 3 天）。可在启动时一起提供有效参数，AI 只补问缺失或无效项。不要求所有权、广告状态、Listing 文本或产品卖点，不打开外部输入页面。

## 结果与阅读方式

首页先看两类核心清单：

- 自然每个观测日出现、广告未观测到且相关性初步通过：未投放可考虑新增；已投放先核查投放状态和展示条件，再考虑提高竞价。
- 广告每个观测日出现、自然未观测到：核查 Listing 文字覆盖与产品相关性，不声称已确认缺词或不相关。

点击统计卡进入关键词清单，再点词查看逐日排名和每次采集证据。更多筛选、八类分布、覆盖口径按需展开。支持导出当前显示词的完整证据 CSV。HTML 可直接用支持现代 JavaScript 的浏览器离线打开。

“未观测到”不等于“未投放”；“持续出现”不等于排名稳定；未知值不能当无排名。三天为默认连续数据日窗口，并非三次独立最近记录。单日明确标注；缺日不拼接，分页失败、口径或字段歧义会阻止相应建议。
